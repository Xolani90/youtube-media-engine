# Privacy Policy

_Last updated: 2026-09-27_

## 1. Overview
YouTube Media Engine ("the Service") is an internal automation tool
operated by Xolani Tshabalala. This policy describes what data the
Service processes and how.

## 2. Data We Process
The Service processes:
- Content it generates or sources for publishing (video, audio, text).
- Authentication credentials (access tokens) for connected publishing
  platforms (YouTube, Facebook, TikTok), used solely to publish content
  to accounts we control.
- Operational logs needed to run and debug the pipeline.

The Service does not collect data from, or about, end users of the
platforms it publishes to. It has no public-facing login, account
system, or user data collection of its own.

## 3. Data Storage
Credentials and operational data are stored locally/in our own
infrastructure and are not shared with third parties except as
required to call the platform APIs they belong to (e.g. sending a
YouTube access token to YouTube's own API).

## 4. Data Retention
Credentials are retained only as long as needed for active platform
integration and are revoked/rotated as needed.

## 5. Changes
This policy may be updated at any time.
